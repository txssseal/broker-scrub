# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

In short: be respectful and constructive. Harassment, discrimination, and
personal attacks are not tolerated. We're here to help people take back control
of their personal data — extend that same good faith to each other.

Report unacceptable behavior **privately to the maintainer** (contact details are
on the maintainer's GitHub profile) — not in a public issue, and not via the
security-advisory channel (that's reserved for vulnerabilities). Maintainers may
remove, edit, or reject contributions and comments that violate this policy.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
